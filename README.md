# Custom Linux File System

A custom file system implemented in C++ for Linux environments. This project demonstrates core operating system concepts by managing internal data structures, block allocation, and file operations.

## Architecture & Features
* **Data Allocation:** Manages storage blocks and internal file mapping (similar to inodes).
* **Core Operations:** Supports fundamental file system operations such as creating, reading, and writing files.
* **Memory Management:** Strictly handles memory and pointer operations in C++ to maintain file system integrity.

## Technologies Used
* C++
* Linux OS Concepts
